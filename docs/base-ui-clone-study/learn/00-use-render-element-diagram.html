Base UI Clone Study

useRenderElement Render Pipeline

public component가 계산한 state, ARIA props, 사용자 props를 공통 pipeline에서 합쳐 기본 태그, React element override, render function override 중 하나로 최종 element를 만든다.

입력

기본 태그 element

'div', 'button', 'input'처럼 render prop이 없을 때 사용할 태그.

사용자 props componentProps

className, style, render와 사용자가 넘긴 DOM props.

내부 렌더 재료 params

state, ref, ARIA props, role, 사용자 element props 배열.

useRenderElement 내부 처리

1

공통 props 추출

className, style, render를 componentProps에서 꺼낸다.

2

ref 병합

forwarded ref와 render=<element />에 있던 ref를 합친다.

3

props 병합

내부 ARIA props와 사용자 DOM props 배열을 mergeProps로 합친다.

4

state attributes 생성

{ orientation: 'vertical' }을 data-orientation="vertical"로 바꾼다.

5

outProps 완성

data attributes, ARIA, 사용자 props, className, style, ref가 하나의 props 객체가 된다.

출력

render function

render(outProps, state)를 호출해서 사용자가 반환한 element를 사용한다.

React element override

React.cloneElement(render, clonedProps)로 사용자가 준 element에 props를 주입한다.

기본 태그

React.createElement(element, outProps)로 기본 태그를 렌더링한다.

Separator가 state와 ARIA props를 준비 → useRenderElement가 공통 렌더링 규칙을 적용 → 최종 DOM element 생성

컴포넌트 책임

기본 태그, state, ARIA, public props 해석을 담당한다.

hook 책임

props 병합, ref 병합, render override, state attribute 생성을 담당한다.

사용자 책임

원하는 태그, className, style, render function을 선택한다.

설계 효과

모든 public component가 같은 커스터마이징 규칙을 공유한다.
